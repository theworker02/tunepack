# tunepack

Tune encode/decode helpers for pack payloads in pipelines.

**Site:** https://theworker02.github.io/tunepack/

## Install / run

```bash
git clone https://github.com/theworker02/tunepack.git
cd tunepack
node src/cli.js
node --test
```
